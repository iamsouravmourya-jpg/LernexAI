1. BRAND IDENTITY, VISION & DESIGN SYSTEM
================================================================================

A. Brand Core:
- Brand Name: LernexAI
- Logo Icon: Stylized graduation cap + isometric layered knowledge cube with white/gold accents inside an indigo-to-purple gradient container (rounded-xl, 40x40px).
- Slogan / Tagline: "Master Practical Skills with Interactive AI"
- Core Value Proposition:

  in-browser code/spreadsheet sandboxes, 24/7 bilingual (Hinglish/English) AI doubt
  solving with sub-2s responses, and tamper-proof QR-verified certificates with
  formal academic grades (O, A+, A, B, C).

B. Color Palette (Tailwind CSS compatible):
- Primary Accent: Indigo (#4F46E5, indigo-600) to Purple (#9333EA, purple-600) gradients.
- Dark Canvas / High Contrast Sections: Slate-900 (#0F172A), Indigo-950 (#0B0F19), Slate-950 (#020617).
- Light Background: Pure White (#FFFFFF) to Slate-50 (#F8FAFC), subtle Indigo-50/30 wash.
- Success / Verified: Emerald (#10B981, emerald-500/600), Emerald-50 background.
- Warning / Highlight Badges: Amber (#F59E0B, amber-500/600), Amber-50 background.
- Danger / Pain Points: Rose (#F43F5E, rose-500/600), Rose-50 background.
- Border Grays: Slate-200 (#E2E8F0) and Slate-100 (#F1F5F9).

C. Typography:
- Font Family: Plus Jakarta Sans / Inter for crisp UI and body; Playfair Display / Serif accents strictly reserved for academic certificate canvas.
- Hierarchy:
  * Hero Heading: 3xl to 6xl, font-black (font weight 900), tracking-tight, leading-[1.1].
  * Section Titles: 3xl to 5xl, font-black (font weight 900), tracking-tight.
  * Card Titles: lg to xl, font-bold (font weight 700).
  * Body Text: 14px to 16px (text-sm to text-base), leading-relaxed, text-slate-600.
  * Eyebrow Badges: 11px to 12px (text-xs), font-bold, uppercase tracking-wider with glowing dot or icon.

D. Key UI Patterns:
- Floating Pill Navigation bar with backdrop-blur-xl and subtle shadow.
- Ambient background blur orbs (Indigo-200/30, Purple-200/30) that gently float.
- Fine tech-grid background lines (32px x 32px grid pattern with 4% opacity).
- Interactive Live Demos directly on the landing page (users can type doubts and see instant answers without signing in).
- Rounded Corners: 2xl (16px) to 3xl (24px) for cards; rounded-full for buttons and pills.
